# Event entertainment & photography

- `event-dj-entertainment` — a four-hour DJ package with extra hours, add-ons and per-mile travel.
- `event-photography-coverage` — hourly coverage with a two-hour minimum, an assistant photographer for large events and printed albums.

## Try it

```bash
npm run validate -- --strict --catalog examples/events-entertainment/catalog
npm run scenarios -- --catalog examples/events-entertainment/catalog --scenarios examples/events-entertainment/scenarios
npm run simulate -- event-photography-coverage --catalog examples/events-entertainment/catalog --interactive
```
