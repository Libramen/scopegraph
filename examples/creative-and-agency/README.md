# Creative & agency

- `brand-identity-package` — discovery plus one of three tiers, with a naming add-on.
- `copywriting-per-word` — per-word rates that drop with volume, a technical premium and a minimum order.
- `corporate-headshots` — a per-person price, with an on-site setup fee and mileage for office sessions.
- `video-production` — pre-production, a crew-size day rate per shoot day and editing per edit day.
- `website-build` — a base build plus inner pages, CMS and integrations, with a rush surcharge by launch date.

## Try it

```bash
npm run validate -- --strict --catalog examples/creative-and-agency/catalog
npm run scenarios -- --catalog examples/creative-and-agency/catalog --scenarios examples/creative-and-agency/scenarios
npm run simulate -- website-build --catalog examples/creative-and-agency/catalog --interactive
```
